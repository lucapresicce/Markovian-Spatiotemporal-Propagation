# Outputs

All the numbers, figures, and results of the experiment in "_Dynamic Bayesian Predictive Stacking via Markovian Spatiotemporal Propagation_", and its Supplementary Section, are gathered here, as directly written by the execution of code in the `script` folder. To this end, a short presentation of the `plots` folder contents follows.

<!--

-->

**Note:** The output file `replications_results.RData` is **not included in this repository** because its size exceeds GitHub's 100 MB limit (the file is approximately 9 GB). However, it is **fully reproducible** by running the script [`MclosedMopen-simulation.R`](../script/MclosedMopen-simulation.R).  
Please be aware that this script may take a **long time to execute**, depending on your system's resources. If needed, the original `replications_results.RData` file can be provided upon request.
